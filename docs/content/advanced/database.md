# Database

Avleon ships with two database integrations: **TypeORM** for an entity/repository
model, and **Knex** for a query builder. Both are optional peer dependencies —
install the one you use, along with its driver.

::: code-group
```sh [TypeORM]
npm i typeorm pg
```
```sh [Knex]
npm i knex pg
```
:::

## TypeORM

Register the datasource on the app with `useTypeORM`. It is asynchronous, so
await it before the app runs.

```ts [app.ts]
import { Avleon } from '@avleon/core';
import { User } from './models/user';
import { UsersController } from './controllers/users.controller';

const app = Avleon.createApplication();

export async function setup() {
  await app.useTypeORM({
    type: 'postgres',
    host: 'localhost',
    port: 5432,
    username: 'postgres',
    password: 'postgres',
    database: 'myapi',
    entities: [User],
    synchronize: true, // development only
  });

  app.useControllers([UsersController]);
  return app;
}

export default app;
```

```ts [serve.ts]
import { Environment, inject } from '@avleon/core';
import app, { setup } from './app';

async function serve() {
  await setup();
  const env = inject(Environment);
  await app.run(env.get<number>('PORT') || 4000);
}

serve();
```

::: info
The project generated by `avleon new` compiles to CommonJS, where top-level
`await` is not available. Wrap async setup in a function and await it from your
entry point, as above.
:::

### Defining an entity

```ts [models/user.ts]
import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn } from 'typeorm';

@Entity({ name: 'user' })
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  name: string;

  @CreateDateColumn()
  createdAt: Date;
}
```

Generate one with the CLI:

```sh
npx avleon make:model user --orm
```

### Injecting a repository

Use `@InjectRepository` to receive a TypeORM `Repository` in any service or
controller. It also has a `paginate()` method, so type it as
`PaginatedRepository`:

```ts [services/user.service.ts]
import { AppService, InjectRepository, PaginatedRepository } from '@avleon/core';
import { User } from '../models/user';

@AppService
export class UserService {
  constructor(
    @InjectRepository(User)
    private readonly userRepository: PaginatedRepository<User>,
  ) {}

  findAll() {
    return this.userRepository.find();
  }

  page(page: number) {
    return this.userRepository.paginate({ page, perPage: 20 });
  }

  findByPk(id: number) {
    return this.userRepository.findOneBy({ id });
  }

  create(body: Partial<User>) {
    const user = this.userRepository.create(body);
    return this.userRepository.save(user);
  }
}
```

### Using a config class

Instead of an inline object, `useTypeORM` also accepts an `@AppConfig` class.
This keeps credentials in one place and gives access to the environment:

::: code-group
```ts [config/database.config.ts]
import { AppConfig, AvleonConfig, Environment } from '@avleon/core';
import { DataSourceOptions } from 'typeorm';
import { User } from '../models/user';

@AppConfig
export class DatabaseConfig extends AvleonConfig<DataSourceOptions> {
  config(env: Environment): DataSourceOptions {
    return {
      type: 'postgres',
      url: env.get<string>('DATABASE_URL'),
      entities: [User],
    };
  }
}
```

```ts [app.ts]
import { Avleon } from '@avleon/core';
import { DatabaseConfig } from './config/database.config';

const app = Avleon.createApplication();

export async function setup() {
  await app.useTypeORM(DatabaseConfig);
  return app;
}

export default app;
```
:::

### Custom repositories

Extend `AvleonRepository` to keep queries in one class, with pagination and
transactions built in. Query operators (`Like`, `ILike`, `In`, `Not`, `Between`,
`LessThan`, `MoreThan`, `IsNull`, `Any`, `Raw`, `Equal`, `ArrayContains`) are
exported from `@avleon/core`.

```ts [repositories/user.repository.ts]
import { AvleonRepository, Repository, Like } from '@avleon/core';
import { User } from '../models/user';
import { AuditService } from '../services/audit.service';

@Repository(User)
export class UserRepository extends AvleonRepository<User> {
  constructor(private readonly audit: AuditService) {
    super();
  }

  search(term: string, page = 1) {
    return this.paginate(
      { where: { name: Like(`%${term}%`) } }, // TypeORM find options
      { page, perPage: 20 },
    );
  }

  rename(id: number, name: string) {
    return this.transaction(async (tx) => {
      await tx.update({ id }, { name });
      await this.audit.log('rename', id);
    });
  }
}
```

::: warning
In 0.3.0, a `@Repository` class must declare a constructor that calls
`super()`, even with no dependencies. Without one, resolving it through
dependency injection fails on the first query.
:::

- `transaction(work)` joins a transaction that is already active instead of
  opening a nested one. The `tx` repository keeps your injected dependencies.
- `withManager(manager)` returns a copy bound to another `EntityManager`.

## Knex

Register the connection with `useKnex`, which takes a Knex config or an
`@AppConfig` class just like `useTypeORM`:

```ts [app.ts]
import { Avleon } from '@avleon/core';

const app = Avleon.createApplication();

export async function setup() {
  await app.useKnex({
    client: 'pg',
    connection: process.env.DATABASE_URL,
  });
  return app;
}

export default app;
```

Inject `KnexDB` to reach the query builder through its `client` property:

```ts [services/report.service.ts]
import { AppService, KnexDB } from '@avleon/core';

@AppService
export class ReportService {
  constructor(private readonly db: KnexDB) {}

  activeUsers() {
    return this.db.client('user').where({ active: true }).select('*');
  }

  page(page: number) {
    return this.db.paginate(this.db.client('user').orderBy('id'), { page, perPage: 20 });
  }
}
```

`KnexDB` throws if it is resolved before `useKnex` has run, so always register
the connection during app setup. `paginateKnex(query, { page, perPage })` does
the same as `db.paginate` without injecting `KnexDB`.

## Pagination

Every paginator takes `{ page, perPage }` and returns the same shape:

| Source | Call |
|--------|------|
| `@InjectRepository` | `repo.paginate({ page, perPage })` |
| `AvleonRepository` | `this.paginate(findOptions, { page, perPage })` |
| `KnexDB` | `db.paginate(query, { page, perPage })` |
| `Collection` | `collection.paginate({ page, perPage })` |

```json
{
  "data": [ ... ],
  "meta": { "total": 57, "page": 2, "perPage": 20, "lastPage": 3, "next": 3, "prev": 1 }
}
```

`page` defaults to 1 and `perPage` to 10. `next` and `prev` are page numbers.
They are `null` at either end. The `Paginated<T>` and `PageRequest` types are
exported.

## Without a database

For prototypes and tests, `Collection` gives the same shape of API over an
in-memory array — see [Controller](/core-concept/controller) for an example.
